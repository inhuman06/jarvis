JARVIS: Hybrid AI Windows Assistant
JARVIS is a context-aware desktop assistant that automates Windows OS workflows using natural language. It utilizes a hybrid-intelligence routing system to seamlessly switch between local and cloud-based AI models, acting as a centralized command center for your PC.

Features
Deep Windows Integration: Control system settings, manage files, launch apps, and execute command-line scripts via natural language.

Ollama (Local-First): Processes sensitive data and offline system commands locally for zero-latency, privacy-focused execution.

ChatGPT (Advanced Reasoning): Handles complex logic, code generation, and sophisticated multi-turn problem-solving.

Gemini (Multimodal & Speed): Leverages high-speed data synthesis and real-time web research capabilities.

Tech Stack: Python, Windows APIs, Ollama, OpenAI API, Google Gemini API.
